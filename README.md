##  Tujuan Proyek
Website ini dibuat dengan tujuan untuk **menampilkan halaman web sederhana** yang bersih dan responsif. Proyek ini berfokus pada implementasi dasar dan kolaborasi antara dua teknologi utama web, yaitu:
* **HTML** – Digunakan untuk membangun struktur dan kerangka dasar halaman.
* **CSS** – Digunakan untuk mengatur tata letak (layout), warna, visual, dan estetika halaman agar terlihat menarik.
